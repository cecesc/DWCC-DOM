Ejercicio 3: Campo Flexible con Botón Fijo

El input debe absorber todo el ancho disponible (flex: 1) y el botón debe mantener su tamaño sin encogerse (flex-shrink: 0).

Ejercicio 4: Tarjetas con Pie Anclado al Fondo

Cada tarjeta debe tener dirección de columna y su pie (.card-footer) debe quedar anclado a la base mediante margin-top: auto.
