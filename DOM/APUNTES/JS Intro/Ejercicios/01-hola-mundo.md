# 01. Ejercicios de hola mundo

[Teoría](../Teoría/01-hola-mundo.md)

**Preparación:** lee la teoría de este tema y trabaja con los conceptos de los temas anteriores.

**Entorno:** consola del navegador o un archivo `.js` ejecutado con Node. Resuelve cada actividad por separado; no necesitas HTML.

Resuélvelos en la consola o en un archivo `practica.js`. Ejecuta cada ejercicio por separado. Los bloques de texto indican la salida que debes conseguir, no código para copiar.

## 1. El saludo oficial

Escribe un programa que muestre exactamente:

```text
Hola Mundo
```

**Comprueba:** una sola línea, sin comillas impresas.

## 2. Presentación de personaje

Presenta a un personaje inventado en tres líneas: nombre, profesión absurda y lugar de origen. Usa una llamada a `console.log` por línea.

Ejemplo de salida válida:

```text
Lola
Domadora de tostadoras
Isla del WiFi perdido
```

## 3. La calculadora disfrazada

Antes de ejecutarlas, predice la salida de estas líneas. Después explica por qué no muestran lo mismo.

```js
console.log("8 + 2");
console.log(8 + 2);
```

**Pista:** ¿cuál de las dos recibe texto y cuál recibe una operación?

## 4. El loro entrecomillado

Consigue que aparezcan las comillas dobles en este mensaje:

```text
El loro gritó: "Quiero vacaciones"
```

**Pista:** las comillas que envuelven toda la cadena pueden ser distintas de las que forman parte del mensaje.

## 5. Taller de reparaciones

Cada línea siguiente tiene un error. Corrígelas por separado y consigue que ambas impriman `Hola`.

Código incorrecto para analizar:

```text
Console.log("Hola");
console.log("Hola);
```

**Comprueba:** explica qué cambiaste y por qué antes de ejecutar la versión corregida.

## 6. Historia desordenada

Escribe una historia de tres mensajes: se abre una puerta, aparece un gato y el gato reclama el castillo. Después cambia el orden de las instrucciones.

**Comprueba:** la salida debe seguir el nuevo orden del código. Usa mensajes distintos para que el cambio sea visible.

## 7. Un cartel, una llamada

Muestra este cartel usando **una sola** llamada a `console.log`:

```text
SE BUSCA
Programador de dragones
Pago: 100 monedas
```

**Pista:** necesitas dos saltos de línea dentro del texto.

## 8. Pantalla de bienvenida

Crea la pantalla de inicio de un juego inventado. Debe tener:

- Un título.
- Una frase de bienvenida.
- Una línea que muestre `Monedas iniciales: 15`, calculando las monedas como `10 + 5`, no escribiendo directamente `15`.
- Un comentario que explique de dónde sale ese bonus.

**Comprueba:** deben imprimirse tres líneas; el comentario no debe aparecer en la salida.

---

**Criterio de finalización:** comprueba los resultados pedidos y explica las decisiones o errores que señale cada enunciado. No basta con copiar una salida fija cuando se pide calcularla.
